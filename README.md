# Карточка товара «Ананасовый улун»

Вёрстка верхней части карточки товара для интернет-магазина чая Teaboom.ru: фото, цены, выбор фасовки и описание. Делал как тестовое задание.

**Демо:** https://alexanderkoldin.github.io/teaboom-product-card/

![Карточка товара на десктопе и на телефоне](docs/preview.jpg)

## Как запустить

Проще всего открыть демо по ссылке выше. Локально: склонировать репозиторий и открыть `index.html` в браузере, ничего устанавливать не нужно.

```bash
git clone https://github.com/AlexanderKoldin/teaboom-product-card.git
```

## Стек

HTML, CSS (Grid, Flexbox, кастомные и логические свойства) и чистый JavaScript без библиотек.

## Что и почему сделал

**Фасовка на radio-кнопках.** По смыслу это выбор одного варианта из четырёх, поэтому взял `radio` внутри `fieldset` с `legend`. Переключение стрелками и озвучка в экранных читалках работают сами, без лишнего JS. Выбранную плашку подсвечивает CSS через `:checked`, а скрипт только меняет цену и артикул. Данные каждой фасовки лежат в `data-*` атрибутах, обработчик один на весь `fieldset`.

**Страница работает без JS.** В разметке сразу стоят цены фасовки по умолчанию. При загрузке скрипт всё равно сверяет цену с выбранной фасовкой: браузер после перезагрузки может запомнить, какой вариант был выбран.

**Цены.** Форматирую через `Intl.NumberFormat`, как в ТЗ: `1 432 ₽` с пробелом между разрядами, копейки только там, где они есть (`326,40 ₽`). Если у фасовки нет скидки, старая цена и плашка «Скидка!» скрываются. Блоку с ценами задал минимальную ширину, иначе кнопка «В корзину» прыгала при переключении на 100 г.

**Доступность.** Кружки radio спрятаны визуально, но доступны с клавиатуры. Рамка фокуса видна только при навигации клавиатурой (`:focus-visible`). Перед зачёркнутой ценой стоит скрытый текст «Старая цена:», потому что читалки зачёркивание не озвучивают, а `aria-live` объявляет новую цену после смены фасовки.

**Картинка и шрифт.** Фото отдаётся в WebP (на 21% легче) с запасным JPG, у `<img>` прописаны размеры, чтобы вёрстка не прыгала при загрузке. Open Sans подключён локально, только три нужных начертания.

## Где отошёл от сайта

Цвета, шрифт и общий вид взял с teaboom.ru. Отличия:

- вместо четырёх строк с отдельными кнопками один переключатель, одна цена и одна кнопка, как просили в ТЗ;
- категория и описание стоят рядом с ценой, на сайте они в хлебных крошках и во вкладке;
- цена `#e00000` вместо `#ff0000`: контраст на белом вырос с 4.0 до 5.0, норма WCAG AA от 4.5;
- старая цена и артикул `#707070` вместо `#808080`, тоже ради контраста;
- цена крупнее (24px вместо 18px), артикул 12px вместо 9.8px, чтобы его можно было прочитать на телефоне;
- текст на зелёной кнопке тёмный: у белого на `#80bc14` контраст всего 2.3;
- размеры шрифтов округлил: дробные 18.2px и 12.74px на сайте получаются из `em` в Bootstrap.

## Что бы доработал

- Отклик на нажатие «В корзину»: сейчас кнопка ничего не делает.
- Hover только для устройств с мышью (`@media (hover: hover)`), чтобы на телефоне кнопка не залипала жёлтой после тапа.
- Превью ссылки для соцсетей (Open Graph).
